# Atlas Manager backup rehearsal

The deterministic rehearsal composes disabled deployment, managed mock
administration, protected target and run APIs, manual mock execution,
scheduled claims, retention, filesystem-tree copying, shutdown readiness, and
dashboard visibility in temporary sandbox roots.

It uses no real backup source, remote storage, Docker, PM2, systemd, Cloudflare
endpoint, helper, RTC, D-Bus, host, or VM. Equivalent runs with different
temporary roots must produce identical bounded evidence bytes and hashes.
