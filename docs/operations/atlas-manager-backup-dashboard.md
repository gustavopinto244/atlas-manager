# Atlas Manager backup dashboard

The same-origin dashboard displays registered targets, safe run metadata, and
local-only backup status. Manual execution, scheduling, and retention actions
use operation-specific confirmations and reread authoritative state after each
mutation.

The dashboard does not display source paths, destination paths, file names,
manifests, contents, or download links. Restoration is explicitly unavailable.
Cloudflare Access and server-side role authorization remain mandatory.
