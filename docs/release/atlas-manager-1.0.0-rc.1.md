# Atlas Manager 1.0.0-rc.1

This is a software-only release candidate. It consolidates the protected
administrative APIs, closed route catalog, browser security envelope, identity
readiness checks, managed configuration replacement/rollback, backup and event
history milestones, deployment bundle, and deterministic sandbox evidence.

The supported production profile remains loopback-only, Cloudflare-authenticated,
role-authorized, audited, mock-power, and disabled for real machine-power
effects. No restore operation, remote backup replication, external audit
attestation, or general administration CLI is included.

Stable physical release remains blocked by the separately approved Atlas
deployment and ingress qualification drill, including real Tunnel/Access,
helper ownership, RTC, wake, and shutdown acceptance.
