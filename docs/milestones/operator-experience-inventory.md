## Reconciliation conclusions

- Presentation code calls existing protected APIs and shared application/domain
  capabilities; it does not own authorization, scheduling or power rules.
- The dashboard power component imports the canonical shutdown confirmation
  constants and accepts only bounded server response shapes.
- Wake/shutdown controls are absent unless their administrative feature flags
  are enabled. Their source implementation remains mock-safe while effects and
  the machine scheduler are disabled.
- The remaining material operator-experience gap is a reviewed identity model
  for mutating CLI commands, not missing backend service logic.
